# Patrouille Nounours / Патруль Мишки

A cooperative police-mystery game for a child (phone or tablet) and an adult (computer), connected with WebRTC.

Play: open the GitHub Pages address of this repository on the computer, choose **Commissaire Minou**, then scan the QR code with the phone.

`index.html` is the single-file build of `game7_police` (`build.ps1`). It includes PeerJS 1.5.4 and qrcode-generator 1.4.4 (both MIT).
